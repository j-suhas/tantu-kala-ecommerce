## Goal

One command each to check: files changed are in the branch owner's scope, new dependencies are on the approved list, and no personal data or secrets are committed.

## Acceptance criteria

- [ ] `npm test` runs Vitest with at least one passing smoke test, and `npm run format:check` exists (NFR-8).
- [ ] `check-scope` fails a diff that touches an owner-only path (`CLAUDE.md`, `.claude/`, `.github/`, `wrangler.jsonc`, `.env*`) and passes a normal docs-only diff; demonstrated with a fixture, not the real repo history.
- [ ] `check-deps` fails when `package.json` gains a dependency not on the approved list (Preact, Vitest, Playwright per D-27/D-28, Prettier per IN-15 once approved).
- [ ] `check-pii` fails on a fixture containing a 10-digit Indian phone number, an email address, a UPI ID or a long hex/base64 token, and passes on the current repo; any hit in the current repo is **reported, not edited**.
- [ ] The proposed CI workflow is written as text in the PR description for the owner to install.
