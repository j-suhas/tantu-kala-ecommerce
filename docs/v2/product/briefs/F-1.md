## Goal

One typed source of truth for products, campaigns, collections, the cart and the Apps Script envelope, usable by both the site and `apps-script/`.

## Acceptance criteria

- [ ] `Product` has every required and optional field in ARCHITECTURE §3.1, with `status` as the four-value union and tags typed as prefixed strings.
- [ ] API types cover every action in LLD-05 §3 with request and response, and the shared envelope from LLD-05 §2 (success/failure is carried in the body: every reply is HTTP 200).
- [ ] The existing `src/data/products.json` type-checks against `Product` with no edits to the JSON (run `astro check`, paste the result).
- [ ] No runtime code, no imports from `src/pages` or `src/components`; the file is plain types so Apps Script tooling can reuse it.
- [ ] `npm run format:check` and `astro check` pass.
