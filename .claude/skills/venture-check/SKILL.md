# Venture check (tk-analyst)

Credits: phuryn/pm-skills `identify-assumptions-new`, `pre-mortem`, `market-sizing` (MIT);
Teresa Torres' product risks; github/spec-kit idea assessment (MIT).

1. **Frame:** the decision in one sentence; what "worth it" means (₹, time, brand); deadline.
2. **Assumptions** across value, usability (for buyers/shops), viability (margin after
   materials, making hours, packaging, shipping, commissions), feasibility (making capacity,
   Delhi/Pune logistics), go-to-market (channels we actually have), ethics/legal (flag for a
   professional). Rate each: confidence low/medium/high; impact if wrong.
3. **Pre-mortem:** "It's six weeks later and this failed — why?" Sort into Tigers (real, act),
   Paper Tigers (overblown), Elephants (nobody is discussing).
4. **Evidence:** prices of comparable handmade pieces, shop margins, demand signals — each with
   source and date; ranges marked "estimate"; bottom-up maths (pieces × price × frequency) over
   big market numbers. Unknown stays unknown.
5. **Verdict:** go / test first / stop, using the analyst output block (Recommendation, Rests
   on, Would change if, Confidence, Cheapest next test with ₹ and days, Unknowns).
6. `humanize` the summary; no jargon Suhas hasn't used.
